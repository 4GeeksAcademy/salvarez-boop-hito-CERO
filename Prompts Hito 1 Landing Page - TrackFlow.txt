# 🛠️ **Requisitos Técnicos del Sitio**

## 🔧 Tecnologías y estructura obligatoria

- **Tailwind CSS v4** como framework principal de estilos  
- **HTML semántico** para accesibilidad y SEO
- **Diseño Mobile‑First obligatorio:**  
  - Estilos base pensados para pantallas pequeñas  
  - Escalado progresivo hacia tablet y escritorio  
  - Uso de breakpoints con min-width  
  - Optimización de carga para dispositivos móviles

⚠️ **IMPORTANTE:**  
Los nombres de campos, IDs de entidad y valores específicos del dominio en tu implementación deben coincidir **exactamente** con lo especificado en tu `CONTEXT-HT1.es.md`.  
Una implementación genérica que ignore el contexto **no será aceptada**.

- **Accesible:**  
  - Uso de etiquetas ARIA cuando sea necesario  
  - Atributos **alt** en todas las imágenes  
  - Navegación clara y compatible con lectores de pantalla  
- **Optimizado para SEO:**  
  - Implementación obligatoria de **Schema.org JSON‑LD**  
  - Estructura semántica correcta  
  - Metadatos completos  
- **Validación completa del formulario con JavaScript:**  
  - Todos los campos deben validarse antes de “enviar”  
  - Mensajes de error claros y visibles  
  - Botón de envío deshabilitado si falta información  
- **Diseño responsive obligatorio:**  
  - Debe verse bien en **móvil**, **tablet** y **escritorio**  
  - Ajuste fluido de columnas  
  - Hero optimizado para pantallas pequeñas  
  - Menú adaptable  
- **Compatibilidad con navegadores modernos** (Chrome, Edge, Firefox, Safari)  
- **Separación de páginas:**  
  - `/index.html` → Landing Page  
  - `/aplicacion.html` → Formulario de Aplicación  
- **Control de errores en tiempo real**  
- **Contador de caracteres** en comentarios  
- **Advertencia automática** para volúmenes menores a 100 envíos/mes  
- **Estructura modular del CSS** (solo Tailwind; evitar CSS manual salvo casos extremos)  
- **No requiere backend por ahora** (solo validación en frontend)

## 🔒 Validaciones Específicas del Formulario

- Nombre de empresa: Mínimo 2 caracteres  
- Persona de contacto: Debe contener al menos nombre y apellido  
- Email: Debe ser formato válido (contener @ y dominio)  
- Teléfono: Debe comenzar con + seguido del código de país  
- Sitio web: Si se proporciona, debe ser una URL válida (comenzar con http:// o https://)  
- Servicios de interés: Al menos una opción debe estar seleccionada  
- Comentarios: Limitar a 500 caracteres con contador visible  
- Política de privacidad: El checkbox debe estar marcado para poder enviar
